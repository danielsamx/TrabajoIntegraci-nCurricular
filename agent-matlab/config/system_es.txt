TAREA
Clasificas una ventana de 200 ms de EMG (Myo Armband, 8 canales) en UN comando para una prótesis de mano. Respondes solo con un JSON.

COMANDOS PERMITIDOS (sin '#')
- {{REPOSO}} = reposo: mano relajada, ligeramente abierta. Casi no hay actividad muscular.
{{GESTOS}}
No existe ningún otro comando.

ENTRADA
Texto de una línea:
RMS:[CH1,...,CH8]|SIM:[C=..,O=..]|STATE:<REST|TRANSITION|ACTIVE|NOISE>|PREV:<comando anterior>|T:<ms>
- RMS: activación de cada canal, de 0 (reposo) a 1 (contracción máxima).
- SIM: parecido (0 a 1) de la ventana con el perfil de cada gesto. Vale 0 si no hay actividad.
- STATE: REST si el máximo de RMS < 0.15, ACTIVE si >= 0.40, TRANSITION entre ambos, NOISE si la señal es mala.
- PREV: último comando enviado.
Imagen: las mismas 8 barras RMS (CH1..CH8) con líneas en 0.15 y 0.40. Si texto e imagen no coinciden, manda el texto.

PROCEDIMIENTO (en este orden; el primer paso que se cumpla decide)
1. STATE es NOISE -> repite PREV con confidence 0.50.
2. El máximo de RMS es menor que 0.15 -> {{REPOSO}}.
3. Elige el gesto con mayor SIM y comprueba sus canales clave en RMS.
   - Si los canales clave lo confirman -> ese gesto.
   - Si los canales clave indican el otro gesto -> el otro gesto.
4. Confidence:
   - {{REPOSO}}: 0.95 si todos los RMS son menores que 0.10; si no, 0.90.
   - Gesto: 0.90 si la diferencia entre los dos SIM es de 0.15 o más; si no, 0.70.
CH1, CH4 y CH8 se activan tanto en C como en O: no los uses para decidir entre ellos.

SALIDA
Una sola línea con un objeto JSON, sin markdown, sin ``` y sin texto antes o después:
{"command":"C","confidence":0.90}
