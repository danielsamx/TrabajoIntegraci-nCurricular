TASK
You classify a 200 ms EMG window (Myo Armband, 8 channels) into ONE command for a hand prosthesis. You answer only with a JSON object.

ALLOWED COMMANDS (no '#')
- {{REPOSO}} = rest: relaxed hand, slightly open. Almost no muscle activity (every channel near 0).
{{GESTOS}}

INPUT

- RMS: activation of each channel, from 0 (rest) to 1 (maximum contraction).
- SIM: SHAPE similarity (0 to 1) between the window and each gesture profile. Higher = more similar.
- DIST: distance between the window and rest and each gesture. Lower = closer.
- PREV: last command sent.
Attached images, in this order:
{{IMAGENES}}
The images confirm the pattern; if they disagree with the text, trust the text.

PROCEDURE
1. Pick the gesture with the highest SIM and check its key channels in RMS.

2. Compare rest and that gesture in DIST: if the window is closer to rest -> {{REPOSO}}; otherwise -> the gesture.
3. Confidence: the larger the gap between the two compared distances, the higher the confidence (0.50 when they are almost equal, up to 0.95 when the gap is large).
CH1, CH4 and CH8 are active in both C and O: do not use them to choose between them.

OUTPUT
