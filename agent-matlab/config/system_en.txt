TASK

ALLOWED COMMANDS (no '#')
- {{REPOSO}} = rest: relaxed hand, slightly open. Almost no muscle activity.
{{GESTOS}}

INPUT

1. STATE is NOISE -> repeat PREV with confidence 0.50.
2. The maximum RMS is below 0.15 -> {{REPOSO}}.
3. Pick the gesture with the highest SIM and check its key channels in RMS.

   - If the key channels point to the other gesture -> the other gesture.
4. Confidence:
   - {{REPOSO}}: 0.95 if every RMS is below 0.10; otherwise 0.90.
   - Gesture: 0.90 if the two SIM values differ by 0.15 or more; otherwise 0.70.
CH1, CH4 and CH8 are active in both C and O: do not use them to choose between them.
