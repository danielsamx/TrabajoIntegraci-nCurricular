// Usuario e interfaz
Usuario > agent_ui: Iniciar / Detener, ajustes
Usuario > main consola
agent_ui > agent_session: un ciclo por periodo
main consola > agent_session
agent_session > agent_ui: dashboard 8 canales, imágenes, comandos
agent_config > agent_session: toda la configuración
system prompt es en > build_system_prompt: GESTOS, REPOSO, IMAGENES
build_system_prompt > agent_session: system prompt final

// Adquisición
Myo Armband > Adaptador BLED112: BLE, EMG 2 x 8 int8
Myo Armband > Bluetooth del PC: alternativa
Adaptador BLED112 > myo_interface: serie BGAPI
Bluetooth del PC > myo_interface
myo_interface > agent_session: ventana 200 ms, 40 x 8

// Procesamiento
agent_session > process_signals
Filtros sin toolbox > process_signals: Butterworth 20-95 Hz + notch
process_signals > build_payload: RMS, SIM, DIST
process_signals > Imágenes PNG: características, ondas, envolvente

// LLM
agent_session > list_llm_models: al iniciar
list_llm_models > GET v1 models: comprobar servidor y modelo
build_payload > send_input_llm: RMS|SIM|DIST|PREV|T
Imágenes PNG > send_input_llm: base64
send_input_llm > POST v1 chat completions
POST v1 chat completions > Modelo de visión
POST v1 chat completions > parse_llm_response: JSON command, confidence
parse_llm_response > smooth_command: válido (S, C, O)
parse_llm_response > log_msg y logs: inválido, no se envía nada

// Prótesis
smooth_command > send_prosthesis_command: mayoría / confianza
send_prosthesis_command > HTTP api command
send_prosthesis_command > Puerto serie COM
send_prosthesis_command > Bluetooth SPP
HTTP api command > ESP32 firmware
Puerto serie COM > ESP32 firmware
Bluetooth SPP > ESP32 firmware: letra + LF
ESP32 firmware > Motores de los dedos

// Registro
agent_session > log_msg y logs: consola completa
